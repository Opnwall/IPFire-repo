## 已通过

- 官方 EasyTier 2.6.4 Linux x86_64 ZIP 与 Release API SHA-256 一致；捆绑 core/CLI 和 LGPL-3.0 上游许可证。
- 6 项配置回归测试：默认关闭开机启动、合法配置、空密码保留、无效字段/URL/类型/端口/网段拒绝、固定地址和网段序列化、引号不能注入 TOML。
- 目标机 shell/Perl/Python 语法、sudoers 校验；以 nobody 身份渲染真实 CGI。
- 无效 CSRF 拒绝；通过真实 CGI POST 保存；密码不出现在 HTML 和 status JSON；开机启动勾选和取消均生效。
- 两个独立 EasyTier 进程，其中对端位于临时网络命名空间，使用专用网络名称/密码及临时 IPv4 网段建立 TCP 隧道。虚拟地址 ping、节点列表和路由查询通过。不使用用户已有 VPN 账号或公网中继。
- 实际确认管理 RPC 仅监听 `127.0.0.1%lo:15889`。此版本管理 RPC 是进程级参数，不能依赖 TOML 中的 `rpc_portal`；已通过显式 CLI 参数修正。TUN 模块按需加载。
- 候选安装器安装 → 停止 → 卸载 → 检查插件拥有的程序、配置、sudo、菜单、启动项无残留 → 重装通过。卸载配置备份保存在主机 `/root/easytier-uninstall.62W1fS/config/`，含测试密码，不应上传公开仓库。
- 测试临时 ICMP/传输规则、命名空间和 veth 已清理；IPv4 防火墙忽略计数器/生成时间后与测试前一致，全部路由表逐字节一致，Apache 配置和正常 DNS 查询通过。
